# 365-popups

Imagens públicas usadas nos popups do 365dasorte.com.br (tags no Google Tag Manager).

Servidas via jsDelivr, sempre com versão fixa:

```
https://cdn.jsdelivr.net/gh/Garllards01/365-popups@v1/img/logo-365-popup.png
https://cdn.jsdelivr.net/gh/Garllards01/365-popups@v1/img/moeda-365.png
```

Para trocar uma imagem: suba o arquivo novo, crie uma nova release (v2, v3...) e atualize a URL no popup.
